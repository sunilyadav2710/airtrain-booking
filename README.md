# airtrain-booking
Advance Train & Airway Booking System  
This project is a web application built using Google Apps Script with a frontend in HTML/CSS and backend connected to Google Sheets. It provides:

🚆 Railway & Airway Booking Interface – Assigned Users can log in and book customer entries of tickets booking

🔑 Login & Authentication – Secure login form with username and password.

📊 Expense Management Dashboard – Tracks booking expenses and manages records.

⚡ Gross Profit vs Office Expense vs Net Profit- Track with visible bar chart

📂 Google Sheets Integration – All booking data is stored and managed in Google Sheets. 

👍 Master Sheets - tracking of yearly gross profit, net profit, distribution of expense among users, yearly booking count and as annum record
👍 Dashboard Sheets - tracking of monthly gross profit, net profit, distribution of expense among users, monthly booking count and record

🌐 Frontend Hosting – Can be deployed on GitHub Pages for static UI, while backend runs on Google Apps Script.

📂 **Tech Stack**
Frontend: HTML, CSS, JavaScript

Backend: Google Apps Script (Code.gs)

Database: Google Sheets

Hosting: GitHub Pages (frontend), Google Apps Script (backend)
